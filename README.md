# 📊 Student Marks Analyzer

A Python mini project that analyzes student marks using Python fundamentals.

## Features

- Accepts marks for 10 students
- Stores marks in both List and Tuple
- Calculates Total Marks
- Calculates Average Marks
- Finds Highest Mark
- Finds Lowest Mark
- Separates Even and Odd Marks
- Removes Duplicate Marks
- Displays Sorted Unique Marks
- Counts Pass and Fail Students
- Assigns Grades (A, B, C, D, Fail)
- Creates Topper List and Tuple
- Allows analyzing another class

## Concepts Used

- Functions
- For Loops
- Conditional Statements
- Lists
- Tuples
- List Methods
- Tuple Conversion
- zip()
- Data Analysis

## Grade Criteria

| Marks | Grade |
|-------:|:------|
| 90–100 | A |
| 75–89 | B |
| 60–74 | C |
| 35–59 | D |
| 0–34 | Fail |
